# analysis —— 两项独立的策略验证研究

这个目录里的东西**不构建策略、不交易**,只回答"这东西到底成不成立"。
两项研究互相独立,但方法论一致:**先把命题写成可证伪的形式,再用能穿越危机的样本去打它。**

```
analysis/
  factor_ic.py      →  factor_report/   我们自己动量因子的 IC 分析(Alphalens)
  upro_regime.py    →  upro_report/     对一个公开杠杆择时策略的诚实复现
```

---

## 一、`factor_ic.py` —— 我们自己的因子,到底有没有预测力?

拿纸面交易与回测**共用的那个大脑**(`momentum_scores` = 12-1 动量 / 波动),问一个问题:
**按这个因子给股票排序,能不能把未来的赢家和输家分开?**

管线:Tiingo 日线(缓存)→ 每个月末算因子 → Alphalens `get_clean_factor_and_forward_returns`
→ Rank IC + 分位收益 → 4 张图 + `factor_report/summary.txt`。

### 结果

| 预测周期 | 平均 IC | IC 标准差 | ICIR | t 值 | 胜率 |
|---|---:|---:|---:|---:|---:|
| 1 天 | 0.0204 | 0.2804 | 0.07 | 4.46 | 53.6% |
| 5 天 | 0.0230 | 0.2792 | 0.08 | 5.05 | 54.8% |
| 21 天 | 0.0168 | 0.2636 | 0.06 | 3.90 | 53.2% |

### 结论:**统计上真实,经济上极弱**

- **t 值 3.9–5.0 → 不是运气。** 这个因子确实携带信息,方向是对的。
- **但平均 IC 只有 0.017–0.023**,低于股票因子"还行"的经验区间(0.03–0.05);
  **ICIR 仅 0.06–0.08**(因子的"夏普"),**胜率 53%** —— 只比抛硬币好一点点。

**这一条独立印证了组合层面的结论。** 主策略回测出 IR ≈ 0,组合层面的解释是"现金拖累";
而因子层面的解释更根本:**这个 alpha 源本身就太薄**,薄到任何仓位管理都救不回来。
两条互不依赖的证据指向同一结论 —— 这比单一回测结果有力得多。

## 二、`upro_regime.py` —— 一个公开杠杆择时策略的诚实复现

复现某财经博主推广的 SPY/UPRO 杠杆择时(内核是 Gayed 2016《Leverage for the Long Run》):
**趋势判多头时持 3 倍杠杆,判空头时降险。** 用 QQQ 的 200 日均线当多空线。

**我做的两处关键改动,都是为了让它可被证伪:**

1. **把窗口拉回 2000 年。** 用 SPY 按 3 倍日收益复利、扣成本来模拟 UPRO,这样能测穿
   **2000 互联网泡沫**和 **2008 金融危机** —— 而原推广者的 2010 / 2017 起点恰好绕开了这两次。
   (真实 UPRO 2009-06 才存在,不模拟就根本测不了。)
2. **把"胜率 70% 的波段"换掉。** 原策略里空头端那部分没有可执行定义、无法证伪,
   替换成两个标准且明确的版本:**熊→现金** 和 **熊→SPY(1x)**。

**诚实声明(写在脚本里):** 成本按 2.5%/年估计(ER + 融资),高利率年份实际更高
→ 我们的模拟 UPRO **偏乐观**;未计税费和切换滑点 → **也偏乐观**;信号滞后 1 天,**无前视**。

### 结果:2000–2026(含两次大考)

| 策略 | 年化 | 最大回撤 | 波动 | Sharpe | MAR | 累计 |
|---|---:|---:|---:|---:|---:|---:|
| SPY(1x 持有) | 8.3% | −55.2% | 19.3% | 0.51 | 0.15 | 729% |
| QQQ(1x 持有) | 8.7% | −83.0% | 26.8% | 0.45 | 0.10 | 808% |
| **UPRO(3x 裸持)** | **10.7%** | **−97.1%** | 57.9% | 0.47 | 0.11 | 1381% |
| Regime:熊→现金 | 14.8% | −63.0% | 36.6% | 0.56 | 0.23 | 3741% |
| Regime:熊→SPY | 16.2% | −72.7% | 39.6% | 0.58 | 0.22 | 5271% |

### 同一个"3x 裸持",换个窗口就换个人格

| 窗口 | UPRO 3x 裸持年化 | 最大回撤 |
|---|---:|---:|
| 2010–2026(原推广者窗口) | **32.8%** | −76.2% |
| 2017–2026(原推广者另一窗口) | **35.2%** | −76.2% |
| **2000–2026(含两次崩盘)** | **10.7%** | **−97.1%** |

UPRO 裸持的分年度:**2000 −39.5% / 2001 −42.0% / 2002 −61.8% / 2008 −85.3%**。
3 倍杠杆裸持在 2000–2026 的最大回撤是 **−97.1%** —— 实质上归零。
而且它的 **Sharpe 0.47 还低于 SPY 的 0.51**:承担 3 倍波动,换回来的是更差的风险调整收益。

### 结论:思路有效,但展示方式具误导性

- **趋势择时本身确实有价值。** 熊→SPY 版年化 16.2% vs SPY 的 8.3%,MAR 从 0.15 提到 0.22。
  在完整样本里,它是成立的。
- **但它的全部价值来自"避开 2000 和 2008"** —— 而这恰恰是原推广者窗口里**没有**的东西。
  证据:在 2010–2026 窗口内,**不做择时(32.8%)反而跑赢做择时(26.3%)**。
- **所以原推广者展示的窗口,恰好是最不需要他那套择时的窗口**;而他用来吸引人的高收益,
  来自那个在完整历史里会让你亏掉 97% 的裸持杠杆。
- **即使是有效的择时版,最大回撤仍有 −63%~−73%**,远不是一个"稳健"策略。

## 复现

```bash
cd ~/quantsys && export PATH="$HOME/.local/bin:$PATH"

# 因子 IC(需要 alphalens)
uv run --with alphalens-reloaded --with matplotlib --with scipy python analysis/factor_ic.py

# 杠杆择时(数据已缓存,不走网络)
uv run --with matplotlib python analysis/upro_regime.py
```

两个脚本都会把图和 `summary.txt` 写进各自的 `*_report/` 目录,结论可复现、可核对。
